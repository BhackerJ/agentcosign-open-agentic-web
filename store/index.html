Try the demo in three steps

One dock here, the Demo Dock Duo, does not list how many 4K displays it drives. The demo request needs two, so the buyer agent should stop and say so rather than order it.

  1. Open the Buyer Desk, a buyer agent on another site. Select Fill in the demo request, then Send. When it asks to use this store's tools, select Allow.
  2. When the agent has answered, select Share this run with the store below its chat.
  3. Come back to this page. Under What buying agents ran into here, the store lists the run once its answers match what the store gave, and counts it against the Duo's missing spec.
